# Fuse - Reverse Engineered Google Keep

Fuse is a fast, lightweight, offline-first note-taking application reverse-engineered from Google Keep. It is built for offline note-taking and taking notes without titles, with no calendar and no Google reminders added. Capture begins on your first keystroke without distractions or delays.

## Features

- Automatic Saving: Notes save automatically as you write, when clicking outside, or upon pressing Escape. There is no save button and no risk of lost thoughts.
- Body-Only and Title-Free: Designed without title fields for easy and immediate thought capture.
- Strictly Zero Bloat: Strictly no calendar views, no reminders, no Google Calendar sync, and no Google Tasks integration. Just pure, instant notes.
- Google Labels System: Global and in-context label management that allows tagging and filtering notes effortlessly.
- Interactive Checklists: Seamless one-click conversion between freeform text and interactive checklists.
- Priority Color Palette: Twelve dual-theme Google Keep colors with Coral, Storm, and Clay prioritized for semantic status.
- Responsive Layout: High-density masonry card grid that adapts across mobile phones and desktop screens.

## How to Run It

### Prerequisites
Node.js 18 or higher and npm.

### Installation

Clone the repository and install dependencies:
```bash
git clone https://github.com/emmanuelcascacius-cloud/fuse.git
cd fuse
npm install
```

### Development

Start the local development server:
```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the application.

### Production Build

Build and run the production server:
```bash
npm run build
npm start
```

### Run Tests

Execute the automated test suite:
```bash
npm test
```
